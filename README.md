# কুরআন ট্রেনিং একাডেমি (Quran Training Academy) — LMS ওয়েবসাইট

## অ্যাডমিন প্যানেল

ঠিকানা: `আপনার-সাইট/admin.html` (সাইটের ফুটারে "অ্যাডমিন প্যানেল" লিংকও আছে)

- **মোবাইল নম্বর:** 01724649947
- **পাসওয়ার্ড:** প্রথমবার যেটা দেওয়া হয়েছে — লগইন করে **পাসওয়ার্ড** অংশ থেকে বদলে নিন।

কিছু বদলালে নিচে **"সব পরিবর্তন সেভ করুন"** বার আসে — সেভ চাপলেই ওয়েবসাইটে সাথে সাথে দেখা যায়।

## GitHub এ আপলোড

কোনো ফোল্ডার নেই — সব ফাইল এক জায়গায়।

1. ZIP আনজিপ করুন।
2. GitHub রিপোজিটরিতে **Add file → Upload files**।
3. আনজিপ করা ফোল্ডার খুলে **Ctrl+A** দিয়ে সব ফাইল সিলেক্ট করে আপলোড করুন।
4. **Commit changes** চাপুন।

`api.mjs` হলো সার্ভারের ফাইল (ডাটাবেস, লগইন, ছবি আপলোড)। Netlify বিল্ডের সময় এটাকে নিজে থেকেই সঠিক জায়গায় নিয়ে চালু করে।

## Netlify সেটিংস

- Netlify নিজে থেকেই `netlify.toml` পড়ে নেবে (Build command ও Publish directory এখানেই লেখা)। Netlify তে আগে কিছু লিখে থাকলে **Site configuration → Build & deploy → Build settings** এ Build command ও Publish directory খালি করে দিন।
- কোনো টোকেন বা অতিরিক্ত সেটআপ লাগবে না — ডাটাবেস (Netlify Blobs) নিজে থেকেই চালু হয়।
- Deploy শেষ হলে `admin.html` এ লগইন করুন।

- পাসওয়ার্ড কাউকে দেবেন না।

## ট্র্যাকিং (Facebook Pixel + Conversions API + Google Analytics)

অ্যাডমিন প্যানেল → **ট্র্যাকিং (Pixel)**:
1. **Pixel ID** (আর চাইলে GA4 ID) লিখে নিচের বার থেকে **সেভ** করুন।
2. Events Manager → Pixel → Settings → Conversions API → **Generate access token** — টোকেনটি প্যানেলে বসিয়ে **টোকেন সেভ করুন**।
3. টেস্টের সময় **Test Event Code** দিয়ে **টেস্ট ইভেন্ট পাঠান** চাপুন; ঠিক থাকলে পরে Test Event Code ফাঁকা করে দিন।

যেকোনো সময় প্যানেল থেকে বদলানো বা বন্ধ করা যায় — নতুন করে আপলোড লাগে না। অনুমোদন দিলে টাকার পরিমাণসহ **Purchase** ইভেন্ট সার্ভার থেকে যায়।
